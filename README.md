# Terminal blog

## Run Instructions

- clone the repo
- run go mod tidy
- put your posts in .md files in ./posts/
- also put a hello.md file in ./posts/
- run go run .

## SSH Instructions

- run `ssh localhost -p 6942` from another terminal
